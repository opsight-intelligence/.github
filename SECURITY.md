# Security policy

This is the default security policy for every Opsight Intelligence repository
that does not carry its own. It says how to report a vulnerability privately.

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a security
problem.

Report it privately by opening a security advisory on the affected repository:
go to its **Security** tab and choose **Report a vulnerability** (GitHub private
vulnerability reporting). Only the maintainer can see the report.

Include what you can of:

- the repository, and the version, tag or commit affected;
- what the problem is and what an attacker could do with it;
- steps or a minimal example that reproduces it.

## What happens next

The report is acknowledged in the advisory thread, investigated, and fixed in a
new release where it is confirmed. You are kept informed there, and credited in
the published advisory if you wish.
