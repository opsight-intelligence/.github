# Changelog

All notable changes to the organisation profile are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses semantic versioning.

## [Unreleased]

## [0.2.1] - 2026-11-17

### Added
- `SECURITY.md` and `CONTRIBUTING.md` as the organisation-wide defaults, shown on
  every repository that does not carry its own. Vulnerabilities are reported through a
  private security advisory on the affected repository; external contributions need the
  maintainer's agreement first.
- `LICENSE`: the profile is published for viewing only, all rights reserved.
- `.github/CODEOWNERS` naming the maintainer as owner of every path.

## [0.2.0] - 2026-11-02

### Added
- Clickable preview image of the platform map under the profile title, light and dark, kept identical to the
  Opsight-Architecture-Overview README at v0.2.0.

## [0.1.0] - 2026-11-02

### Added
- Profile README section linking the public interactive platform map and the open-source OpSentry repositories,
  kept identical to the Opsight-Architecture-Overview README.
- `VERSION` and this changelog; the repository now follows Git Flow with a `develop` branch.
