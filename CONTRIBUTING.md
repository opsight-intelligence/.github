# Contributing

This is the default contributing guide for every Opsight Intelligence
repository that does not carry its own. The projects here are maintained by a
single developer.

External contributions are not accepted unless they have been agreed with the
maintainer first. Please do not open a pull request without that agreement; it
will be closed unreviewed.

To raise a bug or suggest a change, open an issue on the repository concerned.
For a security problem, do not open an issue: follow [SECURITY.md](SECURITY.md)
instead.
